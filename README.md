# Galaxy Adventure 2D

Galaxy Adventure 2D is a 2D action-platformer game developed in Unity using C#.  
This project was created as my BCA final-year academic project.

## Project Type
Academic Project – Guided Tutorial Based  
Solo Developer

## Technologies Used
- Unity
- C#
- 2D Sprites
- Unity UI System
- Animator

## My Role
- Designed and implemented gameplay mechanics
- Implemented player movement and controls
- Created enemy and obstacle behavior
- Designed UI elements (menus, score, health)
- Integrated animations and scene transitions
- Debugged and tested the complete game

## Features
- 2D player movement and jumping
- Enemy obstacles and hazards
- Health and scoring system
- Multiple levels / scenes
- UI menus and HUD

## What I Learned
- Unity editor workflow
- C# scripting for gameplay
- Scene and UI management
- Debugging and problem-solving
- Completing a full game project as a solo developer
